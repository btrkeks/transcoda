# Evaluation

The README gives the four strict reproduction commands. `scripts/verify_tools.py`
rescales no values and changes no scoring policy. It retains the frozen scalar
density thresholds, substitutes the hashes of the rebuilt tools, and accepts them
only after page scores, conversion statuses, renderability and aggregates match.
A mismatch is an error. All aggregate statistics and 50,000-resample bootstrap
intervals must equal the frozen summaries. Paired intervals use aligned frozen
baseline page scores, which are not regenerated by this release. The verifier
pins `OPENBLAS_NUM_THREADS=1` and `OMP_NUM_THREADS=1` before importing NumPy,
as in the frozen scoring launcher. Thread-dependent matrix-product summation can
otherwise change document-cluster bounds in the last floating-point bits.

Both references and Transcoda predictions use `serialize-jsonl --preset humdrum-kern
--input-dialect transcoda-v2`. This includes parser validity checks. A conversion,
parse or scoring failure counts as 100. No repairs are applied. The constrained
decoder's rest padding is part of inference. The evaluation mask is in
`config/evaluation-profiles/transcoda-real-ground-truth-v1.json`.

To score newly generated predictions, use a verified density-cut file from the
corresponding reproduction run. For example:

```sh
uv run --no-sync python -m pipelines.baselines.evaluate   --release evaluation/imslp-real-public.json   --predictions outputs/public-cd.jsonl --model-label Transcoda   --model-family transcoda --prediction-format transcoda-v2   --kern-parser target/release/kern_parser   --verosim-bin external/verosim/build/verosim   --density-cut-points outputs/public-cd/verified-density-cut-points.json   --out outputs/new-public-scores --resamples 50000 --seed 20260726
```

Use `evaluation/synthetic-test.json` and the synthetic verified cuts for synthetic
predictions. The evaluation output records exact tool hashes, conversion commands,
per-page diagnostics and bootstrap settings. Scores are fractions internally;
the paper multiplies them by 100. Page seed is 20260726 and document seed is 20260727.
Density seeds are recorded in every frozen summary. Renderability means Verovio
renders every page to non-empty SVG. Strict renderability also requires no error.

The public cohort has exactly 202 pages. Neither the additional 307 test pages,
the validation references nor the Polish references are included.
